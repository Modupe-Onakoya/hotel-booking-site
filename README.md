## Overview
A responsive hotel booking web application that allows users to explore available hotels and rooms, filter results, view detailed room information, and manage their bookings. The project focuses on creating a smooth, intuitive user experience with responsive layouts, interactive features, and a clean modern interface.


## Features
- Browse available hotels and rooms
- Search and filter rooms by destination, price, and room type
- View detailed room information and available amenities
- User authentication and account management
- Create and manage hotel bookings
- Responsive design across desktop, tablet, and mobile devices
- Interactive UI with smooth animations and transitions
- Dynamic navigation and routing between pages
- Clean and intuitive user interface


## Tech Stack
- React
- Tailwind CSS
